# Runway

Know what you can safely spend today. Runway is a small spending tracker that installs to an iPhone home screen and works offline. Your money data stays on your phone. Nothing is sent anywhere.

- **Install it:** see [HOW-TO-INSTALL.md](HOW-TO-INSTALL.md).
- **How it works and why:** see [PLAN.md](PLAN.md).
- **Rules for changing it:** see [CLAUDE.md](CLAUDE.md).

Plain HTML, CSS and JavaScript. No build step, no dependencies.

```bash
node --test            # run the tests
node tools/serve.js    # preview at http://localhost:8080/runway/
```
